# Phase 5: Delivering

## Before handover

Recompute the headline numbers once more from the raw records and compare with what the page displays. Fix or annotate any discrepancy. If the page fails to render, that is a bug for you to fix now, not something to hand over. Never ask the user to debug anything; they cannot read an error message and should never need to.

## The handover

Hand over the three deliverables and one sentence on how to open the page (for an `.html` file: "double-click it and it opens in your browser").

## Close with exactly three things, briefly

1. **The top actions this week** from the alert list, with names and amounts.
2. **How to refresh**: re-export the data, start a fresh conversation, ask for the dashboard again, and bring the new files. The page is a snapshot and will not update itself.
3. **The 1 to 3 columns to start filling in** that would most improve the next run.

## Do not offer to build more pages

One page that gets acted on beats five.
